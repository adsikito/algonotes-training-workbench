# AlgoNotes v1.4 · 学习工具与文件闭环

这是在原私人工作台上的增量增强。原7题池、STL讲义、题下笔记、个人结果与掌握自评继续保留；没有新增社交功能，也没有改动原每日任务。

## 去哪里用

- **侧栏 → 学习工具**：错题与反例、关联与分类、代码模板、限时训练、统计与选题、复习收件箱、资料问答包及工具回收站。
- **知识与STL → 接口速查**：现有110组接口的常用调用、返回、代价、边界和就地代码示例。原23模块讲义继续可用。
- **笔记与资料 → 上传/导入**：单文件256MiB试点、8MiB分块、整文件校验、同一原件续传；账户原件总额度仍为1GiB，包含回收站和各版本。
- **资料阅读器 → 进入专注阅读**：独立阅读链接、目录、阅读设置；本机自动保留位置，跨设备可点“同步阅读位置”。不会因阅读自动记为掌握。
- **备份管理**：新备份用4MiB附件块，云端元数据先形成一致快照后分页打包；全部分包确认后才可下载。可以从新版云端备份校验并恢复为独立副本，也兼容原本地旧版恢复。
- **设置与数据**：查看原件、回收站、备份和上传预留的实际用量，导出本机未同步草稿，管理未完成上传。
- **Ctrl/Cmd+K**：搜索题目/笔记/讲义，或快速执行新建笔记、上传、导航和备份等操作。

## 新模块的实际行为

错题本由你主动收录，保留当前尝试的代码和测试快照，可补最小反例、原因、修正与验证。状态分开记录，修正不自动等于验证通过。模板库记录C++版本、适用条件、复杂度、代码和本地测试，可下载CPP；网站不执行代码。

关联用稳定ID连接题目、笔记、原件、讲义、分类和模板。可从两端查回，来源回收后仍保留关系信息。分类支持父子关系、别名和知识点/题型维度；它还没有替代全站所有旧标签筛选。

统计显示已记录时间与未知用时，图表旁有数据表和日期回查。预算建议只从当前题池按可解释规则选择，并允许换题，不会改写原题单。限时训练记录开始、暂停、切题日志和复盘，结束不会自动给题目记AC。

输出比较支持逐字符、忽略行尾空白和按空白分词三种模式，报告首个差异。历史文本比较展示相同前后段之间的变化区间，不是自动合并工具。

资料问答包只整理你明确选中的不超过5个来源，附来源ID和版本，下载前可预览。没有接入模型、OCR或Office转换服务，不会伪造AI回答。

## 上传、下载与备份边界

- 上传原件单文件256MiB，单批最多200项/1GiB；原件总额度1GiB，上传时原子预留额度。未完成会话保留24小时；重新选择同一原件可复用已确认分块。
- 展开课程ZIP仍限压缩20MiB、展开100MiB、文件与目录合计200项。显式空目录可保留；浏览器文件夹选择器不能提供纯空目录。上传ZIP原件与展开ZIP是两个操作。
- 大文件下载分块读取并校验SHA-256。支持文件选择器的浏览器直接写磁盘；其他浏览器用本机内存暂存，较大原件建议在桌面端保存。
- 备份最多1000个分包，历史与原件都纳入校验；需保留全部分包（最后一包是V2清单）。分包单独不是完整备份。
- 受保护备份不自动过期，也不能直接删除；先解除保护，再删除整套。清理失败保留逐项回执，可重试；删除备份不删除资料原件。
- 恢复采用稳定映射后的新ID，不覆盖已有记录，同一快照重复恢复不会翻倍。旧历史作为独立归档保留。原件额度不足时会停止并说明，不会伪称完整恢复。

## 验收证据

- 当前110组速查内容完整性检查；65组独立程序逐字输出核对；共73份不同程序用C++11/C++17编译运行。
- TypeScript、既有领域/文件/备份/回收/阅读/分页检查，以及新增学习模型、比较器、5000层目录、续传、ZIP空目录和V2备份集成测试。
- 真实预览D1/R2隔离自检41项全部通过，包括共享内容事务回滚、重复批次幂等、私人账号隔离、原件校验、保护/删除与失败续清理。
- 实际上传256MiB、64MiB测试原件；实际生成约320MiB、101/101分包完整备份；全包核验后恢复28条当前记录与45条历史为独立副本，目录及笔记原件链接可回查，原记录保留。
- 这些是隔离预览与本地检查，不等同生产环境长期压测，也不代表通知到达、已读或题目完成。
